# Home Intercom PTT

Стеклянная Lovelace-карточка Push-to-Talk для интеграции [Home Intercom](https://github.com/mdj2812/home-intercom).

Карточка устанавливается отдельно от основной интеграции и добавляется на любой дашборд Home Assistant.

## Возможности

- Push-to-Talk: удерживайте кнопку для записи, отпустите для отправки.
- Отправка в отдельную комнату или во все комнаты сразу.
- Отображение доступности комнат.
- Визуальный редактор конфигурации.
- Настройка внешнего вида, цветов, размеров, подписей, иконок и раскладки.
- Стеклянное оформление, подсветка и анимация записи.

## Требования

- Home Assistant.
- Установленная и настроенная интеграция [Home Intercom](https://github.com/mdj2812/home-intercom), предоставляющая API `/api/home_intercom`.

## Установка через HACS

1. Откройте **HACS → Frontend**.
2. Откройте меню в правом верхнем углу и выберите **Custom repositories**.
3. Добавьте `alshevskij/home-intercom-lovelace` с категорией **Dashboard**.
4. Найдите **Home Intercom PTT** и установите.
5. Перезагрузите страницу Home Assistant (при необходимости очистите кэш браузера).
6. Добавьте карточку на дашборд через **Добавить карточку → Home Intercom PTT**.

## Ручная установка

1. Скопируйте `home-intercom-ptt-card.js` в каталог `config/www/`.
2. В **Настройки → Панели управления → Ресурсы** добавьте ресурс:
   - URL: `/local/home-intercom-ptt-card.js`
   - Тип: **JavaScript Module**.
3. Перезагрузите страницу Home Assistant.

## YAML

Минимальная конфигурация:

```yaml
type: custom:home-intercom-ptt-card
```

Остальные параметры доступны в визуальном редакторе карточки.

## Совместимость

Карточка является frontend-дополнением. Она не заменяет основную интеграцию Home Intercom и использует её backend API.
